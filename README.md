# Site Oficial - Plynexa ⚡

Este é o projeto completo da Landing Page e Estrutura Comercial Institucional da **Plynexa**, desenvolvido em **Next.js 14 (App Router)** com **TypeScript, Tailwind CSS, Lucide Icons e componentes interativos** em React.

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
Certifique-se de ter o **Node.js (versão 18.x ou superior)** instalado em sua máquina.

### 1. Instalar as Dependências
Abra a pasta do projeto descompactado no seu terminal e execute:
```bash
npm install
```

### 2. Rodar em Ambiente de Desenvolvimento
Para testar o projeto localmente com recarregamento em tempo real:
```bash
npm run dev
```
Abra [http://localhost:3000](http://localhost:3000) no seu navegador.

### 3. Build de Produção
Para compilar o código de forma otimizada para produção:
```bash
npm run build
```

## 🌩️ Como Colocar seu Site no Ar de Graça (Vercel)

1. **GitHub**:
   - Crie um repositório vazio no seu GitHub.
   - Envie o código da pasta descompactada para o seu repositório:
     ```bash
     git init
     git add .
     git commit -m "feat: site oficial plynexa"
     git branch -M main
     git remote add origin https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git
     git push -u origin main
     ```

2. **Vercel**:
   - Crie uma conta na [Vercel](https://vercel.com/) vinculada ao seu GitHub.
   - Clique em **"Add New..."** -> **"Project"** no painel da Vercel.
   - Importe o repositório do site e clique em **"Deploy"**.
   - Pronto! Seu site estará público sob um subdomínio `.vercel.app` gratuito de alta performance.
